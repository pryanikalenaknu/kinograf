# КіноГраф: сценарій демонстрації на захисті

Захист складається з двох частин: доповідь за презентацією [`presentation.pdf`](presentation.pdf) (41 слайд) і показ працюючого застосунку.

## Підготовка напередодні

1. Оновити клон: `git checkout main && git pull`.
2. Запустити Docker Desktop і застосунок:

   ```bash
   cp .env.example .env          # задати власний KINOGRAF_ADMIN_KEY
   docker compose up --build
   ```

3. Завантажити дані заздалегідь, а не на захисті: оновлення з Wikidata триває кілька хвилин, і Wikidata може обмежувати запити.

   ```bash
   docker compose exec api python -m kinograf.update
   ```

   Дані зберігаються в томі `kinograf-data` і не зникають після перезапуску.

4. Перевірити, що відкриваються http://localhost:8080 і http://localhost:8080/api/docs.
5. Якщо застосунок треба показати з іншого пристрою, відкрити тунель і задати його адресу в `KINOGRAF_BASE_URL` у `.env`, потім перезапустити й оновити дані:

   ```bash
   cloudflared tunnel --url http://localhost:8080
   ```

## Перед початком захисту

- Ноутбук на зарядці, режим сну вимкнено.
- Застосунок запущено, дані завантажено, у браузері відкрито каталог.
- Ключ адміністратора під рукою (для екрана «Адміністрування»).
- Презентацію відкрито в повноекранному режимі.

## Порядок показу застосунку

1. **Каталог.** Пошук за назвою, фільтри за роками, жанром і режисером, експорт результатів у CSV, JSON або Turtle.
2. **Картка фільму.** Фільм «Поводир»: учасники, жанри, нагороди, пов'язані фільми, посилання на Wikidata, IMDb і Вікіпедію.
3. **Персоналія.** Перехід із картки фільму на режисера чи актора: фільмографія й хронологія.
4. **Граф зв'язків.** Хто з ким працював: фільми й персоналії як вузли графа.
5. **Статистика.** Фільми за роками, жанри, топ-10 режисерів і акторів.
6. **Якість даних.** Повнота за полями й зауваження перевірки SHACL.
7. **SPARQL-консоль.** Готовий запит із прикладів, результат у таблиці, експорт.
8. **Відкриті дані.** П'ять зірок відкритих даних, постійні адреси, опис набору VoID, завантаження набору.
9. **Адміністрування.** Вхід за ключем, журнал оновлень.

Для програми-клієнта — запит у терміналі:

```bash
curl -L -H "Accept: text/turtle" http://localhost:8080/id/film/Q12141247
```

## Якщо щось пішло не так

- **Немає інтернету.** Застосунок працює з локальними даними: Wikidata потрібна лише для оновлення. Не запускати оновлення на захисті.
- **Застосунок не запускається.** Показати знімки екранів із [`screenshots/`](screenshots) і слайди 29–33 презентації.
- **Питання про тести.** Запустити приймальні тести: `cd e2e && npm test` (17 сценаріїв).
